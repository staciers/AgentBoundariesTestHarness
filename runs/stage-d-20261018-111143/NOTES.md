## Confirmatory outcome

**Decision rule met:** D1, D2 and D3 are all confirmed. P6's delegation rules improve outcomes
with the runtime held fixed, at both runtime levels.

| ID | Result | Verdict |
|---|---|---|
| D1 | success, non-base, semantic runtime: P6 65% vs P1 19% | confirmed |
| D2 | the same with no runtime: P6 65% vs P1 16% | confirmed |
| D3 | harm, semantic runtime: P1 9% vs P6 4% | confirmed |
| D4 | harm, semantic runtime: P3 34% vs P6 4% (B5, deconfounded) | confirmed |
| D5 | autonomous success, semantic runtime: P6 34% vs P4 13% (B4, deconfounded) | confirmed |
| D6 | harm under hidden write, P6 with no runtime vs semantic: 4% vs 3% | **not confirmed** |
| K1 | harm on `authority` tasks: P6 without the authority gate 90% vs P6 0% | confirmed |
| K3 | harm under hidden write, no runtime: P6 routing to the agent 21% vs routing to a human 4% | confirmed |
| K2 | success: P6 77% vs P6 without the confidence gate 76% (±5 points) | equivalent |

**Reading:**
- **The delegation effect is not an artefact of the runtime.** P6 minus P1 is +45 to +50
  points of success on non-base tasks, in every fault × runtime cell.
- **Only two of P6's three parts do the work:** the deterministic **authority gate** (K1), and
  **routing unresolved execution outcomes to a human** (K3). The confidence gate is inert (K2),
  firing about 0.1 times per 100 episodes. Models almost never report low confidence.
- **D6 failed because P6's routing substitutes for the runtime.**
  - With no runtime, P6 routes unknown outcomes to a human (37.8 per 100 episodes), and harm
    stays at 4%.
  - The cost moves to human attention: interventions per task rise from 0.45 to 0.84, and
    autonomous success falls from 34% to 20%.
  - The interaction terms agree: the runtime matters less under P6 than under P1 (success
    p = 0.009; harm p = 0.006).
  - So, for unobservable execution outcomes, **the runtime buys autonomy, and routing buys
    safety.** Either prevents harm; only the runtime does it without a human.

## Exploratory (not pre-registered)

**Agent-selected escalation with the same runtime nearly matches P6.**

| Policy, semantic runtime | Success | Harm |
|---|---|---|
| P5 | 79% | 6% |
| P6 | 77% | 4% |

The two differ by task type:

| Variant | P5 success / harm | P6 success / harm |
|---|---|---|
| `authority` | 85% / 9% | 88% / **0%** |
| `ambiguous` | **52%** / 8% | 42% / 12% |
| `base` | 100% / 0% | 100% / 0% |

- P6's distinctive value over "the agent asks, plus the runtime" is the **deterministic
  authority gate**: it removes the 9% authority harm.
- P5 handles ambiguity better, because agents ask about ambiguity they recognize; P6 gives them
  no `ask_human` tool.
- This suggests a **P5 + P6 hybrid** (an authority gate plus `ask_human`), which may dominate
  both. It is a candidate hypothesis for the next study, and the strongest baseline a reviewer
  would ask for.

**By family** (semantic runtime, success / harm):

| Family | P1 | P5 | P6 |
|---|---|---|---|
| Closed | 48% / 4% | 80% / 5% | 77% / 4% |
| Open | 43% / 15% | 78% / 6% | 76% / 4% |

The delegation effect holds in both families.
