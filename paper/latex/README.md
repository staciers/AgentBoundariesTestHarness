# LaTeX version of the paper (USENIX template)

| File | What it is |
|---|---|
| `main.tex` | The paper, generated from `../full.md` by `md2tex.py` |
| `references.bib` | The bibliography (47 entries; those marked `note = {To confirm}` still need checking) |
| `md2tex.py` | The converter. Re-run it after editing the draft |
| `usenix2019_v3.sty` | The USENIX style file |
| `../figures/*.pdf` | Figures, generated by `../figures/make_figures.py` |

## Regenerate after editing the draft

```bash
python3 paper/latex/md2tex.py
```

For the arXiv version, append the supplement (S1–S5) as appendices so the paper and supplement
are one PDF:

```bash
python3 paper/latex/md2tex.py paper/full.md paper/latex/main.tex --supplement
```

To build the arXiv upload, run `python3 paper/latex/make_arxiv.py` from the repo root. It writes
`paper/arxiv/arxiv-source.tar.gz` (LaTeX, `.bbl`, style file and figures, with flat paths) and a
test build, `paper/arxiv/arxiv-preview.pdf`. Both are ignored by git.

`--anonymous` replaces the author line with "Anonymous submission" (for the OSDI version).

For the OSDI build, add `--repo-url=<anonymized link>` (e.g. from anonymous.4open.science). It replaces
every link to the GitHub repository. An `--anonymous` build refuses to write its output if anything
identifying remains (author name, GitHub user, repository name, email):

```bash
python3 paper/latex/md2tex.py paper/full.md paper/latex/main.tex --anonymous --repo-url=https://anonymous.4open.science/r/<id>
```

Once the draft is frozen, stop regenerating and edit `main.tex` directly; the converter would
overwrite hand edits.

## Build

1. The style file, `usenix2019_v3.sty`, is in this folder. It is the LaTeX style the USENIX
   paper templates page offered on 2026-10-30, which the OSDI '27 author requirements point to.
   USENIX's sample paper (`usenix2019_v3.2-sample.tex`) is kept locally for reference but not committed.
2. Build with any LaTeX distribution that includes `fvextra`, `tabularx`, `booktabs` and
   `longtable` (all in TeX Live and MacTeX):

```bash
cd paper/latex && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Locally, Tectonic (installed in `~/.local/bin`) builds it in one step, running BibTeX itself:

```bash
cd paper/latex && ~/.local/bin/tectonic main.tex
```

Tectonic uses XeTeX, while the USENIX style targets pdfLaTeX. The preamble therefore skips
`breakurl` and microtype's pdfTeX-only kerning and spacing under XeTeX. Line breaks, and so the
page count, can differ slightly from a pdfLaTeX build. Check the final submission PDF with
pdfLaTeX (e.g. on Overleaf) before relying on its page count.

Overleaf works too: upload `paper/latex/` and `paper/figures/` keeping the same layout, since
`main.tex` loads figures from `../figures/`.
